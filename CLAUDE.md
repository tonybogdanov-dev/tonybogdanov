# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Setup

**Important:** Project accessed via UNC path on Windows, but runs in WSL2 distro `x-tonybogdanov` at `/x/x-tonybogdanov`. All Node/NPM commands MUST run inside the distro, not Windows PowerShell.

## Environment

Copy `.env.example` to `.env` and fill it in. `check-env.js` loads `.env` and validates the
required vars (`CONTACT_EMAIL`, `RESEND_API_KEY`, `TURNSTILE_SECRET_KEY`); it gates both `npm run
build` (before the Docker image is built) and `npm start`, which exit with code 1 when anything is
missing. All secrets and the contact address come from the environment only — there is no file-based
fallback. `.env` must never be committed.

## Commands

Run all npm commands via WSL distro using `wsl -d x-tonybogdanov -e`:

**Dev server (Vite with hot reload):**
```bash
wsl -d x-tonybogdanov -e npm run dev
```

**Build (TypeScript + Vite):**
```bash
wsl -d x-tonybogdanov -e npm run build
```

**Start the production server (serves the `.dist` build output; run `npm run build` first):**
```bash
wsl -d x-tonybogdanov -e npm start
```

**Install dependencies:**
```bash
wsl -d x-tonybogdanov -e npm install
```

**Generate the CV PDF (starts a dev server at `localhost:5173` if one isn't already running there, and stops it afterwards):**
```bash
wsl -d x-tonybogdanov -e npm run dev:cv
```

**Generate the LinkedIn cover PNG and the OpenGraph/Twitter preview image (same dev-server lifecycle as `dev:cv` for the OG image):**
```bash
wsl -d x-tonybogdanov -e npm run dev:generate
```

## Architecture

**Language:** TypeScript (ES2020 target, ES modules)

**Stack:** React 18 + Vite + Tailwind CSS

**Structure:**
- `src/` — TypeScript source files (`.tsx` for React components; `pages/Page*` = top-level routed pages, `sections/Section*` = page sections, `components/V*` = visual building blocks)
- `config/` — Data & design-token yaml files (colors, fonts, spacing, breakpoints, content, etc.) shared by the site, Tailwind, and Node scripts
- `config.base.ts` — Shared types + `buildConfig()` that assembles the yaml into a typed `Config`
- `config.browser.ts` — Browser-side config entry (imports yaml via Vite's yaml plugin, resolves skill icons via `import.meta.glob`); used by `src/`
- `config.node.ts` — Node-side config entry (loads yaml from disk directly); used by `scripts/` and `vite.config.ts`, since Node scripts can't go through Vite's import pipeline
- `scripts/` — Node utility scripts (run with `tsx`; not covered by `tsc`, which only includes `src/`): `generate.ts` exports `convertSVGToPNG` (rasterizes an SVG to PNG via `sharp`) and `generateOGImage` (renders the site's `/og` route (`src/pages/PageOG.tsx`) to a 1200x630 PNG via headless Chrome, reusing a dev server at `localhost:5173` if one is already running, otherwise starting/stopping its own), then invokes both to regenerate `assets/linkedin-cover.png` and `public/og-image.png`; `cv.ts` renders the site's `/cv` route (`src/pages/PageCurriculumVitae.tsx`) to PDF via headless Chrome (Playwright), same dev-server-reuse pattern; `screenshot.ts` captures responsive screenshots across breakpoints via BrowserStack + Selenium, output to `.screenshots/`; `svg.ts` minifies + reformats SVG assets
- `patches/` — patch-package patches applied via `postinstall` (currently: `browserstack-local`)
- `public/` — Static files served at the site root (includes the generated `tony-bogdanov-cv.pdf` and `og-image.png`)
- `.dist/` — Compiled output (generated by Vite, gitignored); includes precompressed `.gz`/`.br` siblings for every text asset (via `vite-plugin-compression2`)
- `index.html` — Entry point for the app
- `vite.config.ts` — Vite configuration (includes PostCSS + Tailwind, `build.outDir` set to `.dist`, build-time gzip/brotli compression)
- `tailwind.config.ts` — Tailwind CSS configuration
- `check-env.js` — Loads `.env` and validates the required env vars; gates `npm run build` and `npm start`
- `server.js` — Dependency-free (aside from `sirv`) Node production server: serves `.dist` with precompressed asset negotiation, immutable long-term caching for hashed `/assets/*` files, SPA fallback to `index.html` for any unmatched path, hardened response headers (CSP, HSTS, X-Frame-Options, etc.), GET/HEAD-only, and slowloris-resistant timeouts. Started via `npm start`.

**Content lives in config, not components:** all identity/links, career timeline, skill catalog,
and copy live in `config/*.yaml`, assembled by `buildConfig()` in `config.base.ts` and exposed via
`config.browser.ts` (site) / `config.node.ts` (scripts). Editing these yaml files updates the site
and the generated CV together.

**Styling:** Tailwind CSS for utility-first styling. Apply styles using Tailwind class names in the `className` attribute.

**Build:** Vite bundles React app with hot module replacement in dev, optimized output in production. Tailwind CSS is processed via PostCSS during the build.
